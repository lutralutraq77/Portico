## Audit contract
Events contain sequence, UTC time, action/result enum, immutable actor/target IDs, correlation ID and a redacted change reference. Required actions: authentication success/failure, issuance/enrollment, revocation, resource/grant changes, administrator/factor changes, recovery, security settings, session termination and updates.

Never include private keys, invitation secrets, bearer/cookie values, raw WebAuthn responses, passwords or request bodies. Failed login storms may need rate aggregation without erasing meaningful security events.

A transactional outbox guarantees intent consistency, not tamper-proof storage. An external append-only destination provides independent evidence for records already exported; sequence gaps detect loss. A local hash chain alone cannot resist root rewriting its head and history.

If the audit store is full, deny new grants and permits. Emergency revocation or service shutdown must remain possible through an independently protected local containment path. Record a local recovery journal when possible and reconcile after repair. No claimed “audit succeeded” when storage failed.
